# Lamport Logical Clock Simulator

## Overview
This repository contains a project report on the **Lamport Logical Clock Simulator**, demonstrating logical time and event ordering in distributed systems.

The project explores how Lamport logical clocks assign timestamps to events across multiple independent processes while maintaining causal ordering without relying on synchronized physical clocks.
